name: listener-dual-stack
about: A :: socket without IPV6_V6ONLY takes IPv4 too (ss prints it as *); a v6only one does not.
about: A socket on one IPv6 address takes no IPv4 at all.
--- listen
host tcp :: 8080 dual
host tcp :: 8081 v6only
host tcp 2001:db8:1::10 8082
host udp :: 5353 dual
host udp :: 5354 v6only
--- probes

name: security-table-drop
about: The security table's INPUT chain runs after filter INPUT; an accept in filter does not
about: protect a packet from a drop there.
--- iptables
*filter
:INPUT DROP [0:0]
:FORWARD DROP [0:0]
:OUTPUT ACCEPT [0:0]
-A INPUT -p tcp -j ACCEPT
COMMIT
*security
:INPUT ACCEPT [0:0]
:FORWARD ACCEPT [0:0]
:OUTPUT ACCEPT [0:0]
-A INPUT -p tcp -m tcp --dport 22 -j DROP
-A INPUT -s 198.51.100.7/32 -p tcp -m tcp --dport 80 -j DROP
COMMIT
--- listen
host tcp 0.0.0.0 22
host tcp 0.0.0.0 80
--- probes
eth0 198.51.100.7 203.0.113.10 tcp 22 want:silent
eth0 198.51.100.7 203.0.113.10 tcp 80 want:silent
eth0 198.51.100.200 203.0.113.10 tcp 80 want:open

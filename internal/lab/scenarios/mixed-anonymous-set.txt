name: mixed-anonymous-set
about: An iptables-made filter table with three rules added by nft between and after the iptables
about: ones, each using an anonymous set, which iptables has no words for. iptables-save prints
about: "tcp dport { 25, 587 } accept" as "-p tcp -j ACCEPT" (every TCP port open) and the rule
about: that lets two sources past the reject on 9000 as one that lets everybody past. The kernel
about: does what the nft listing says, and the iptables rules around them keep their details.
--- iptables
*filter
:INPUT DROP [0:0]
:FORWARD ACCEPT [0:0]
:OUTPUT ACCEPT [0:0]
-A INPUT -m conntrack --ctstate RELATED,ESTABLISHED -j ACCEPT
-A INPUT -p tcp -m multiport --dports 80,443 -j ACCEPT
-A INPUT -p tcp -m tcp --dport 9000 -j REJECT --reject-with tcp-reset
-A INPUT -p udp -m udp --dport 53 -j ACCEPT
COMMIT
--- nft
insert rule ip filter INPUT index 1 tcp dport { 25, 587 } accept
insert rule ip filter INPUT index 3 ip saddr { 198.51.100.7, 192.0.2.0/24 } tcp dport 9000 accept
add rule ip filter INPUT udp dport { 123, 5000-5100 } accept
--- listen
host tcp 0.0.0.0 25
host tcp 0.0.0.0 80
host tcp 0.0.0.0 443
host tcp 0.0.0.0 587
host tcp 0.0.0.0 8080
host tcp 0.0.0.0 9000
host udp 0.0.0.0 53
host udp 0.0.0.0 123
host udp 0.0.0.0 5050
host udp 0.0.0.0 6000
--- probes
